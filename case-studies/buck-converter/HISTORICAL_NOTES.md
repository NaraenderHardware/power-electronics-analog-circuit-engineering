# Historical Project Notes: 36V to 18V Buck Converter

These notes summarize the original student repository documentation for the 36V to 18V DC-DC Buck Converter. Historical claims below reflect the initial design intentions and student project submissions; they are not independently verified bench measurements.

## Original Project Scope

The project objective was to design and construct a switched-mode DC-DC buck converter to step down 36V DC to 18V DC at 24W (1.33A load) using 50 kHz pulse-width modulation (PWM) generated by an Arduino Nano and amplified by a Toshiba TLP350 photocoupler gate driver.

## Stated Design Parameters

- Input Voltage: 36V DC nominal
- Output Voltage: 18V DC nominal
- Output Power: 24W nominal (1.33A into ~13.5 Ohm load)
- Switching Frequency: 50 kHz
- Topology: High-side N-channel MOSFET buck converter
- Controller: Arduino Nano (ATmega328P Timer1 Fast PWM Mode 14)
- Gate Driver: Toshiba TLP350 photocoupler driver
- Active Switch: IRLZ44N N-channel power MOSFET
- Freewheeling Diode: 1N5819 Schottky diode (40V, 1A nominal)
- Storage Inductor: 680 uH (calculated nominal in design PDF)
- Output Filter Capacitor: 100 uF electrolytic (design target)

The original repository listed output verification as "in progress" and did not include bench oscilloscope captures, efficiency curves, or load-regulation measurements.

## Discrepancies and Engineering Audit Notes

Independent technical review revealed several significant discrepancies between the historical documentation and the physical artifacts:
- Inductor Component: The physical board photograph shows an installed choke labeled `PCV-2-394-05L` (~390 uH) rather than the 680 uH nominal design value.
- Output Filter Capacitor: Output capacitor footprint C1 is unpopulated in the prototype photograph.
- Diode Voltage Margin: The 1N5819 diode has a 40V reverse breakdown rating, leaving only a 4V static margin against the 36V input.
- Control Mode: Firmware implements fixed open-loop PWM without closed-loop voltage or current feedback.
- Gate Driver Reference: The high-side N-MOSFET requires an isolated floating gate-drive supply referenced to the switching source node.
